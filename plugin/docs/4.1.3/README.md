# Arthas 文档离线镜像（v4.1.3）

本目录是插件早期收录的 Arthas 命令文档，原始文件位于 `plugin/docs/` 根目录（扁平存放），
按版本归类后移到这里。

## 版本是怎么确定的

旧文档本身没有写版本号，`version.md` 里的示例输出 `3.5.1` 只是历史残留的示例，不能作为依据。
因此用「与官方仓库各 tag 的 `site/docs/doc/*.md` 逐页做文本相似度比对」的方式定位：

| 候选版本 | 50 篇平均相似度 | 关键差异 |
| --- | --- | --- |
| 3.6.9 | 0.8939 | `memory`、`profiler` 内容完全不同 |
| 3.7.3 | 0.8977 | 同上；`jad`、`getstatic`、`advice-class` 也不一致 |
| 4.0.0 | 0.9261 | 仍有 `profiler`、`jad` 等差异 |
| **4.1.0 – 4.1.3** | **0.9296（最高，剩余差异全部来自 HTML→MD 转换痕迹）** | — |
| 4.1.4 – 4.1.9 | 0.9345 以下 | `classloader`（0.964 → 0.755）、`stop` 已改版 |

进一步核对：4.1.1、4.1.2、4.1.3 三个 tag 的这 50 篇文档内容**完全一致**，4.1.4 才开始改动
`classloader`、`stop`、`tt`。因此这批文档对应 **4.1.0 – 4.1.3**，目录取其中最新的 **4.1.3**。

## 说明

- 目录内文档为站点 HTML 转换后的 Markdown，格式已由 `plugin/scripts/normalize-md.js` 规范化。
- `docs-list.json` 为菜单顺序与描述，`docs-group.json` 为分组过滤规则。
- 新版本文档见 `../4.3.5/`。
